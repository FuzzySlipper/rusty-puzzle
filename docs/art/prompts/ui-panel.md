# Asset contract: UI panel or frame

Decorative framing for the DOM interface around the board (the side panel,
buttons, the room picker). Words are rendered by the interface, never painted.

- A frame piece or corner on a fully transparent background (real alpha,
  never a painted checkerboard pattern), designed to be used as a nine-slice
  border: ornament concentrated in the corner, straight repeatable runs along
  both edges.
- The panel interior is a calm, low-contrast fill where light text stays
  readable.
- No text, letters, numerals, icons or placeholder labels.
- Square canvas, about 1024 × 1024.
